# NNN – Niharika News Network Birthday Website

## Open the website
1. Extract this ZIP file.
2. Open `index.html` in Chrome, or upload the complete folder to GitHub Pages / Netlify.
3. Keep the folder structure unchanged.

## Add Niharika's photos
- Put the childhood photo in `assets/` and name it `childhood-photo.jpg`.
- Put the latest photo in `assets/` and name it `latest-photo.jpg`.
- If your photo is PNG, update the matching image filename in the HTML.

## Add the background song (all pages)
1. Put your MP3 file inside the `assets` folder.
2. Name it exactly `niharika-song.mp3`.
3. The small NNN Radio control appears on Home, Breaking News and Special Edition.
4. Click **NNN RADIO** once to start the music. It resumes from approximately the same position when moving between pages in the same browser tab.

Browsers generally block sound from autoplaying before the visitor interacts with the page, so the first click is required. The MP3 itself is not included in this ZIP; add your own audio file.

## Pages
- `index.html` – Home and headline
- `breaking-news.html` – The four funny news stories
- `special.html` – Photo gallery and final birthday wish

## Customize
- All styles: `assets/style.css`
- Confetti, radio player and wish button behavior: `assets/script.js`
- Birthday wish text: `special.html`
